## UI philosophy

MeshCore Web Terminal is a technical radio tool, not a dashboard.

The default UI should expose only information required for the
current task.

Prefer removing controls and information over reorganizing them.

Configuration options must not appear in monitoring views.

Advanced information should be shown on demand.

Avoid cards, explanatory text, decorative statistics, and duplicated
navigation context.

Tables should prioritize the most useful information.
Technical identifiers and metadata should be hidden until requested.

A user should be able to understand the main screen at a glance.

Do not fill newly available space with additional UI.
Whitespace is intentional.
